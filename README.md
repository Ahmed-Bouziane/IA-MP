# IA-MP
Développer des modèles intégrant données multimodales pour prédire et prévenir les récidives et aider au diagnostic


Pour lancer l'application :
•	Installer Streamlit à partir d'Anaconda avec la commande suivante : conda install -c conda-forge streamlit
•	Placer le fichier model_pipeline.py sur le Bureau.
•	Ouvrir l'invite de commande (cmd) et taper :  cd C:\Users\Desktop
•	Exécuter le fichier avec : python model_pipeline.py
•	Puis lancer Streamlit avec : streamlit run model_pipeline.py
